## 一、系统概述

SeaPack 提示词模板系统是一个 **可复用的 Prompt 管理平台**，支持跨技能/助手复用的参数化模板。核心设计理念：

| 设计理念 | 说明 |
| --- | --- |
| **模板与变量分离** | 模板正文存储在 `ai_prompt_template`，变量定义存储在 `ai_template_variable`，通过 `template_id` 关联 |
| **占位符渲染** | 模板正文使用 `{{variable}}` 语法定义变量，执行时自动替换为用户输入值 |
| **LLM 直连测试** | 支持在模板管理界面直接调用 LLM API，实时验证模板效果 |
| **跨模块复用** | 模板可被 Skill 技能、Agent 编排、对话助手等多个模块引用 |

:::info
**核心理念**：**<font style="color:#DF2A3F;">模板定义 Prompt 结构，变量填充动态内容，执行引擎完成渲染和 LLM 调用。</font>**

:::

```sql
CREATE TABLE `ai_prompt_template` (
  `id`            BIGINT       NOT NULL AUTO_INCREMENT  COMMENT '主键ID',
  `name`          VARCHAR(100) NOT NULL                 COMMENT '模板名称，如"股票技术分析模板"',

  `description`   VARCHAR(500) DEFAULT NULL             COMMENT '模板用途说明',
  `output_format` VARCHAR(20)  DEFAULT 'markdown'       COMMENT '期望输出格式：markdown/json/text/html',
  `version`       VARCHAR(20)  DEFAULT 'v1.0.0'         COMMENT '版本号',
  `use_count`     INT          DEFAULT 0                COMMENT '被引用次数',
  `status`        TINYINT      DEFAULT 1                COMMENT '1启用 0禁用',
  `created_by`    BIGINT       DEFAULT NULL,
  `created_at`    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at`    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_code` (`code`),
  KEY `idx_category` (`category`),
  KEY `idx_status` (`status`)

```

### (二) 变量定义表 `ai_template_variable`

```sql
CREATE TABLE `ai_template_variable` (
  `id`            BIGINT       NOT NULL AUTO_INCREMENT  COMMENT '主键ID',
  `template_id`   BIGINT       NOT NULL                 COMMENT '所属模板ID',
  `var_name`      VARCHAR(50)  NOT NULL                 COMMENT '变量名，对应 content 中的 {{var_name}}',

  `var_type`      VARCHAR(30)  NOT NULL DEFAULT 'string' COMMENT '变量类型：string/number/boolean/select/date',
  `required`      TINYINT      DEFAULT 1                COMMENT '1必填 0选填',

  `options`       JSON         DEFAULT NULL             COMMENT 'select类型选项 [{label,value}]',

  `created_at`    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_template` (`template_id`)
```

### (三) 两表关系

```plain
ai_prompt_template (模板)
  │
  ├── content: "你是一位分析师，请分析 {{stockCode}} {{stockName}} ..."
  │             ↑ 模板正文中的 {{变量名}} 占位符
  │
  └── 1:N ── ai_template_variable (变量定义)
                 ├── var_name = "stockCode"  ← 对应 {{stockCode}}
                 ├── label = "股票代码"
                 ├── var_type = "string"
                 ├── required = 1
                 └── options = null
```

:::info
**关键设计**：`ai_template_variable.var_name` 必须与 `ai_prompt_template.content` 中的 `{{var_name}}` 严格对应。前端编辑时会自动检测模板正文中的变量并与变量表交叉验证。

:::

### (四) 模板执行流程

:::info
模板执行是核心功能：加载模板 → 替换占位符 → 调用 LLM → 返回结果。

:::

#### 执行流程

```plain
前端 POST /ai/prompt-templates/execute
    │  { templateId, params: {stockCode: "600519", ...}, userMessage: "..." }
    │
    ▼
PromptTemplateService.execute()
    ├── 1. 加载模板: selectById(templateId)
    │      → 返回 PromptTemplate（含 content 和 variables）
    ├── 2. 校验状态: status == 1 ?
    ├── 3. 替换占位符: AiExecuteHelper.replacePlaceholders(content, params)
    │      → "你是一位分析师，请分析 600519 贵州茅台 ..."
    ├── 4. 追加用户补充消息（可选）
    │      → filledPrompt += "\n\n用户补充信息：\n" + userMessage
    ├── 5. 调用 LLM: AiExecuteHelper.callLLM(filledPrompt, ...)
    │      → 构建 OpenAI 兼容格式请求
    │      → 发送到当前激活的 AI 提供商
    │      → 解析响应，提取 output + token 统计
    └── 6. 返回 AiExecuteResult
           { renderedPrompt, output, tokensPrompt, tokensCompletion, durationMs }
```

#### 核心代码：变量替换

```java
// AiExecuteHelper.java
public static String replacePlaceholders(String template, Map<String, Object> params) {
    // 正则匹配 {{variable}} 和 {{ variable }}（支持空格）
    Pattern pattern = Pattern.compile("\\{\\{\\s*(\\w+)\\s*}}");
    Matcher matcher = pattern.matcher(template);
    
    StringBuffer sb = new StringBuffer();
    while (matcher.find()) {
        String key = matcher.group(1);
        Object value = params.get(key);
        String replacement = value != null ? value.toString() : "";
        matcher.appendReplacement(sb, Matcher.quoteReplacement(replacement));
    }
    matcher.appendTail(sb);
    return sb.toString();
}
```

:::info
**代码说明**：

1. 使用正则 `\\{\\{\\s*(\\w+)\\s*}}` 匹配 `{{变量名}}` 格式，支持 `{{ variable }}` 带空格写法。
2. 从 `params` Map 中按变量名取值，替换占位符。
3. 未提供值的变量替换为空字符串。
4. 使用 `Matcher.quoteReplacement` 避免替换值中的 `$` 和 `\` 被误解析。

:::

#### 核心代码：LLM 调用

```java
// AiExecuteHelper.java
public static AiExecuteResult callLLM(String filledPrompt, ...) {
    // 1. 获取当前激活的 AI 提供商配置
    String providerName = aiProperties.getActiveProvider();
    AIProperties.ProviderConfig config = aiProperties.getProviders().get(providerName);
    
    // 2. 构建 OpenAI 兼容格式请求
    String url = config.getBaseUrl() + "/chat/completions";
    Map<String, Object> requestBody = new HashMap<>();
    requestBody.put("model", config.getChatModel());
    requestBody.put("messages", List.of(
        Map.of("role", "system", "content", filledPrompt)
    ));
    requestBody.put("stream", false);
    
    // 3. 发送请求并解析响应
    HttpEntity<Map<String, Object>> entity = new HttpEntity<>(requestBody, headers);
    Map<String, Object> apiResponse = restTemplate.postForObject(url, entity, Map.class);
    
    // 4. 提取 output + token 统计
    AiExecuteResult result = new AiExecuteResult();
    result.setRenderedPrompt(filledPrompt);
    result.setOutput(output);
    result.setTokensPrompt(promptTokens);
    result.setTokensCompletion(completionTokens);
    result.setDurationMs((int) durationMs);
    return result;
}
```

:::info
**执行方式**：将渲染后的 Prompt 作为 `system` 消息发送给 LLM，采用非流式（`stream: false`）调用。返回结果包含渲染后的完整 Prompt、LLM 输出内容、Token 消耗统计和执行耗时。

:::

### (五) 复制模板逻辑

```java
// PromptTemplateService.java
@Transactional
public PromptTemplate copy(Long id) {
    // 1. 查询源模板（含变量）
    PromptTemplate source = templateMapper.selectById(id);
    
    // 2. 创建副本：名称追加"（副本）"，编码追加"_copy"
    PromptTemplate copy = new PromptTemplate();
    copy.setName(source.getName() + "（副本）");
    copy.setCode(source.getCode() + "_copy");
    copy.setContent(source.getContent());
    // ... 复制其他字段
    
    templateMapper.insert(copy);
    
    // 3. 复制变量定义
    List<TemplateVariable> copiedVars = source.getVariables().stream()
        .map(v -> { v.setId(null); v.setTemplateId(copy.getId()); return v; })
        .toList();
    variableMapper.batchInsert(copiedVars);
    
    return copy;
}
```

```vue
<script setup>
/** 从模板正文自动检测变量名 */
const detectedVars = computed(() => {
  const content = form.value.content || ''
  // 正则匹配所有 {{variable}} 格式
  const matches = content.match(/\{\{(\w+)\}\}/g) || []

  return [...new Set(matches.map(m => m.replace(/\{\{|\}\}/g, '')))]
```

| `/ai/prompt-templates/page/list` | GET | 分页查询模板列表（支持分类/状态/关键词筛选） |
| `/ai/prompt-templates/all` | GET | 全量已启用模板列表（下拉选择用） |
| `/ai/prompt-templates/detail/{id}` | GET | 查询模板详情（含变量列表） |

| `/ai/prompt-templates/incrementUse/{id}` | PUT | 增加使用次数 |
| `/ai/prompt-templates/updateStatus/{id}` | PUT | 启停切换（0禁用/1启用） |

### (二) 模板执行

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/ai/prompt-templates/execute` | POST | 执行模板：渲染 Prompt + 调用 LLM + 返回结果 |

**请求体**：
```json
{
  "templateId": 1,
  "params": {
    "stockCode": "600519",
    "stockName": "贵州茅台"
  },
  "userMessage": "请重点关注近期走势"
}
```

**响应体**：
```json
{
  "renderedPrompt": "你是一位分析师，请分析 600519 贵州茅台 ...",
  "output": "贵州茅台近期呈现震荡上行趋势 ...",
  "tokensPrompt": 156,
  "tokensCompletion": 892,
  "durationMs": 12345
}
```

## 七、变量类型体系

| 变量类型 | 前端渲染 | 后端处理 | 示例 |
| --- | --- | --- | --- |
| `string` | `el-input` | 直接替换 | 股票代码：600519 |
| `number` | `el-input-number` | `toString()` 替换 | 字数要求：500 |
| `boolean` | `el-switch` | `true/false` 替换 | 是否包含图表：true |
| `select` | `el-select` | 按选中值替换 | 文章风格：正式/活泼/幽默 |
| `date` | `el-input` (date) | 日期字符串替换 | 数据截止日期：2024-01-01 |
| `text` | `el-input textarea` | 多行文本替换 | 文章内容：长文本 |

## 八、常见问题

### (一) 模板编码重复怎么办？

后端在新增和编辑时会校验 `code` 唯一性：
```java
if (templateService.isCodeDuplicate(template.getCode(), null)) {
    return ResponseEntity.badRequest().body("模板编码已存在: " + template.getCode());
}
```
编辑时通过 `excludeId` 参数排除自身。

### (二) 如何让模板被其他模块引用？

模板设计为跨模块复用，其他模块（如 Skill 技能）可通过以下方式引用：
1. 调用 `GET /ai/prompt-templates/all` 获取已启用模板列表
2. 根据 `code` 或 `id` 定位目标模板
3. 调用 `POST /ai/prompt-templates/execute` 执行模板

### (三) 变量的 options 格式是什么？

`select` 类型变量的 `options` 字段存储 JSON 数组：
```json
[
  { "label": "正式商务", "value": "formal" },
  { "label": "轻松活泼", "value": "casual" }
]
```
前端提交时可能是对象数组，后端 `TemplateVariable.setOptions()` 自动序列化为 JSON 字符串存储。

### (四) 模板执行失败有哪些常见原因？

| 错误信息 | 原因 | 解决方案 |
| --- | --- | --- |
| `模板不存在` | templateId 错误 | 检查模板 ID 是否正确 |
| `模板已禁用` | status = 0 | 在管理界面启用模板 |
| `模板正文为空` | content 字段为空 | 编辑模板填写正文 |
| `AI 配置错误` | 未配置 AI 提供商 | 检查 application.properties 中 ai 配置 |
| `模板执行失败` | LLM API 调用异常 | 检查网络连接和 API Key |
